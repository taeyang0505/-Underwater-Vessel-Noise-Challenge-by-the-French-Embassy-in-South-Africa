# R16 clean support + F1: 두 조건 사전 고정 실행안

## 승인 범위

사용자가 지정한 S1_H0_F1, S1_H15_F1만 새로 학습한다. 이전 2×2 데이터·가중치·435행 평가 및 기존 본체 epoch27을 수정하거나 부분 실행을 이어 쓰지 않는다. Test와 Test 유래 EDA를 읽지 않는다. 알려진 개발 평가를 다시 쓰므로 결과를 새로운 blind 성능이라고 부르지 않는다.

## 데이터

- 두 조건의 양성 3,200건은 이전 D1의 모든 배열을 그대로 사용한다. 자연 support 중앙값5분·≥12분500건을 보존한다. 새 highshare 할당·시간 신축·평탄화 없음.
- S1_H0_F1: 음성800건은 D0의 원래 배열 전부를 그대로 사용한다. HF 교체0건.
- S1_H15_F1: 원래 음성680건을 유지하고 정확120건만 기존 TRAIN-only HF replacement 후보로 교체한다. site/sensor/recorder/실제 마스크 층별 비례 배분 후 고정 hash 순서로 선택한다. 점수·평가 자료를 사용하지 않는다.
- 양성/음성의 site/sensor/recorder/mask 개수는 이전 D0와 같다. H0의 원배경 표본 추출은 원래 정책 그대로다. 유한 표본의 배경만으로 y가 예측되지 않는다는 ‘정확0 AUC’ 또는 모집단 분포의 수학적 동일성은 주장하지 않는다. H15는 음성만 제한 교체한 조건이며 완전 balanced-hf로 부르지 않는다.
- A′75/B19/C′25 선택 그래프 분리 및900초support 기준24시간purge를 그대로 상속한다. 전체509 원천 그래프 독립성으로 과장하지 않는다. 독립 장시간 원천은 C′의 실제12분 컴포넌트1개다.

## 학습

이전 D0F1과 같은 F1, seed2026102817, 소형CNN100epoch/Adam/dropout0.1/early stopping없음, local_fit2400에서 회귀·분류 best checkpoint를 각각 선택한다. Tree최대600round/ES40. 회귀는Share MSE+.25energy-weighted cell MSE, 분류는 독립 파라미터BCE. CPU2프로세스×2스레드. 기존 코드를 import하며 frozen source를 변경하지 않는다.

기본 회귀 결합 Tree60%+CNN40%, 독립 분류 결합Tree50%+CNN50%를 고정한다. 추가 요청대로 새 회귀 예측에 이전 D0F1 독립 분류 score를 붙인 조건도 사전에 명시하여 비교한다. share를 score에 넣지 않으며 잠긴 평가에서 결합 가중치를 최적화하지 않는다.

## 평가·승격 기준

두 조건 학습 완료·SHA동결 후 동일한 별도 배경/B gate, C′참조, 미관측 사이트6연산자, 독립native12 대HF/SF 음성을 한 번 평가한다. 이전 D0F1 저장 예측을 ID·정답 일치 확인 후 재사용한다.

각 후보의 고정 결합 및 사전 지정 D0F1 classifier 분리 결합에 다음을 모두 요구한다.

1. 세 주 축 각각 D0F1 대비 RMSE 악화≤max(.005,5%) 및 classifierAUC 하락≤.02.
2. native12대HF 균형RMSE≤.11 및classifierAUC≥.75, native12대SF 균형RMSE≤.12 및AUC≥.75. .85+는 목표이며 미측정 성능을 보장하지 않는다.
3. HF/SF 음성에서 D0F1 대비 classifier 평균 증가≤.02 및share 평균 증가≤.01.

모두 통과한 후보가 있으면 H0를 우선하고, 같은 데이터에서는 자체 분류기를 우선한다. 사전 순서 H0자체 → H0+D0F1score → H15자체 → H15+D0F1score. 이는 평가 최저값을 찾는 후행 탐색을 막기 위한 보수적 순서다. 이 조건의 ‘통과’는 본체 연결을 허용하는 개발 관문이고 공식 LB 개선을 입증하지 않는다.

통과 즉시 수정 데이터·F1을 새 버전 본체 러너에 연결한다. 기존 다른 레시피 체크포인트에 이어 붙이지 않는다. Tree5-Fold+신경망4종Fold0의 앞서 승인된 범위부터 실행하고 최종 후보CSV를 생성한다. 본체에서Tree회귀최소50%, 개별NN아키텍처최대25%, 독립score를 유지한다. 본체 전수데이터·feature cache·수식·checkpoint1step 검증은 생략하지 않는다.

조건 미달이면 관문을 뒤에서 바꾸거나 실패를 성공으로 표시하지 않는다. 추가 소형 탐색을 자동 반복하지 않고 실측을 보고한다. 99.75%음성 교체가 유력 원인이지만 유일한 원인이었다는 주장은 새 분리 실험으로 검증한다.
