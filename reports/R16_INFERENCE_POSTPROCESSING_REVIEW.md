## 3. 추론을 이해하는 데 필요한 현재 학습 조건

### 3.1 D0/H0와 실제 음원 범위

- **D0:** 기존 자연 궤적 배치. 주로 피크를 포함한 실제 연속 1~6분을 사용하고, 원음이 15분 이하면 일부(선택 확률 25%)는 전체 길이를 사용한다.
- **H0:** 10분 이하 원음은 전체 길이 사용. 긴 원음은 실제 연속 11~15분을 선택한다. 반복, 시간 신축, 가짜 평탄 15분 합성은 하지 않는다.
- 두 조건은 배경·참조 선택·생성 연산자·명시적 무추가 위치를 공유한다. 무추가 샘플의 `db`, `cell_share`, `share`는 조건 간 정확히 같다. **H0라는 이름이 HF hard-negative 교체를 뜻하지 않는다. 현재 실행에는 HF 음성 교체가 없다.**
- 현재 데이터는 보유 VTUAD 509개를 모두 학습에 쓰는 구성이 아니다. **A′ 75클립·13연결 그룹** 안에서 5-Fold를 순환하며, B 19개/C′ 25개 참조를 별도로 남긴다.
- 배경 역시 원본 1,715,779행 전체를 독립적으로 새 분할한 것이 아니라, **기존 R9 Fold0 TRAIN 배경 78,869창 내부의 nested 5-Fold**다. 같은 원천 그룹 분리와 900초 support 기준 24시간 purge를 계승한다.
- 각 구성의 TRAIN 합계는 307,304개다. Fold별 `[61,446, 61,368, 61,259, 61,546, 61,685]`, 각 구성 CV는 Fold당 1,000개다.
- 실제 15분 이상 참조 연결 그룹은 하나뿐이다. 이를 홀드아웃하는 Fold4 TRAIN에는 11분 이상 native 참조가 없는 한계가 있다. 장시간 효과를 여러 독립 선박으로 충분히 검증했다고 주장할 수 없다.

### 3.2 데이터 합성식과 양자화

추가 전 배경 B, 변형된 참조의 추가 에너지 A, 관측 마스크 O에 대해:

\[
E=B+A,\quad q_{tf}=\frac{A_{tf}}{E_{tf}},\quad
y=\frac{\sum O_{tf}A_{tf}}{\sum O_{tf}E_{tf}}.
\]

참조는 먼저 1분 × 25대역 선형 전력으로 변환한 뒤 실제 분 구간을 배치한다. 중·고주파 shelf, 저주파 감쇠, 삽입 전 스케일 처리 차이, 저·고주파 독립 SNR 등을 포함한 6개 사전 정의 연산자를 사용한다. Test 통계에 맞춰 각 샘플의 정답을 강제로 변경하지 않는다.

저장 관측과 입력을 0.1 dB 격자로 맞추지만 **정답 q와 y는 반올림 전 실제 추가 에너지에서 계산한 값**을 보존한다.

\[
d^{Q}_{tf}=\mathrm{round}(10d_{tf})/10,\quad
\widetilde E_{tf}=10^{d^{Q}_{tf}/10},\quad
w_{tf}=\frac{O_{tf}\widetilde E_{tf}}{\sum O\widetilde E}.
\]

오버플로를 막기 위한 창 내 공통 상수 차감은 분자·분모에서 상쇄된다. 반올림 때문에 `sum(w * true_q)`와 원래 y가 수학적으로 완전히 같지는 않다. 데이터 생성·캐시 단계에서 이 차이의 절댓값 **0.0058 이하**를 검사한다. 이를 무시하고 정확한 물리 항등식이라고 표현하면 잘못이다.

## 4. 입력 변환: 현재 17채널

각 창만으로 계산하는 변환이며 Test 전체에서 평균·PCA·prototype 등을 새로 적합하지 않는다.

| 채널(0부터) | 특징 |
|---|---|
| 0 | 대역별 시간 중앙값 대비 dB / 10 |
| 1 | 대역별 시간 q20 대비 dB / 15 |
| 2 | 인접 관측 분 차분 / 10 |
| 3 | 중·고주파 변화와 저주파 동조 상승 특징 |
| 4 | 대역 중앙값 − 창 전체 중앙값, / 20 |
| 5 | 관측 마스크 O |
| 6 | 대역별 시간 q05 대비 dB / 15 |
| 7 | `sqrt(w)` |
| 8 | 대역별 시간 z-score |
| 9~11 | 시간 폭 2·4·8분 이동 평균 상대 특징 |
| 12~14 | 실제 시각 기준 lag 1·2·3분 연속 관측 차분 |
| 15 | q20+3dB 초과의 4분 지속성 |
| 16 | 국소 시간 궤적 곡률 |

- 결측은 관측 마스크로 구분하고 해당 셀의 특징·풀링 가중치는 0으로 둔다. 시간축을 압축해 떨어진 관측 분을 인접 분으로 만들지 않는다.
- q05/q20/중앙값은 **관측 창의 요약 통계**일 뿐, 항상 순수 배경 B를 복원한다는 보장은 없다.
- 절대 `db/100`, 학습된 q0/Bhat prior, 학습 PCA 잔차·LF anchor는 제거했다. 다만 **채널4는 상대 정적 대역 프로파일**이고 채널7도 대역 간 에너지 분포를 담는다. 따라서 “정적 스펙트럼 정보가 완전히 없다”는 표현도 잘못이다.
- 공통 dB offset은 정규화로 상쇄되지만, **대역별로 서로 다른 offset에는 프로파일·w가 변한다.** 임의의 EQ에 모든 경로가 불변인 구조가 아니다. 반올림 경계를 넘는 변환에도 미세 차이가 생길 수 있다.

## 5. 회귀와 독립 분류 경로

### 5.1 신경망

Wide CNN, TFGrid–FDY–Conformer, FDY-CRNN, iTransformer 변형의 회귀기는 셀별 `q_hat`을 예측하고:

\[
\widehat y=\sum_{tf}w_{tf}\widehat q_{tf},\quad 0\le\widehat q\le1.
\]

결측 셀 q_hat을 0으로 처리한다. 이 구조는 출력 범위와 풀링 일관성을 보장하지만 **분해 정확도나 대회 일반화까지 보장하지 않는다.**

독립 분류기는 회귀기와 **공유 파라미터 0개**인 별도 작은 네트워크다. 17채널 중 상대 프로파일(4), `sqrt(w)`(7)를 제외한 15채널을 사용한다. 두 경로의 gradient clipping도 분리한다.

회귀 손실은 `Share MSE + 0.25 * energy-weighted cell MSE`다. 별도 분류기는 presence BCE로 학습하지만 q_hat으로 역전파되지 않는다. 과거 마스크 contrast BCE와 share에 강제 결합한 q0 앵커는 없다.

현재는 각 모델·구성당 **100epoch, Adam, dropout 0.1, early stopping 없음**, cosine LR `0.001 → 0.00001`, weight decay 0.0003이다. 회귀는 local_fit RMSE 최저 체크포인트, 분류는 local_fit AUC 최고 체크포인트를 따로 저장한다. 두 체크포인트의 epoch가 달라도 분류기 파라미터만 독립 로드하므로 회귀 가중치는 변경되지 않는다. Global minimum 발견을 보장하는 방식은 아니다.

### 5.2 LightGBM

- 회귀 **5,160개 특징**: 기존 상대8채널 기반 3,827개 + 시간 구조 특징 1,333개.
- 분류 **2,033개 특징**: 시간 상대 통계·대역 동조·관측 비율 700개 + 시간 구조 특징 1,333개.
- 분류 경로에는 절대 레벨, 상대 정적 프로파일, sqrt(w), 학습 PCA/LF anchor를 직접 넣지 않는다. **관측 비율과 시간 변화의 크기에는 여전히 의존할 수 있다.**
- 추가 특징의 창 내 시간 중심 covariance 고유값은 학습 데이터로 적합한 PCA 잔차와 다르다. 한 창 안에서 계산되는 동조 통계다.
- CPU, 최대 1,500 trees, early stopping 40. 회귀는 clipped RMSE, 분류는 **binary logloss**로 best iteration을 선택한다. 신경망처럼 100epoch를 적용하는 모델이 아니다.
- Tree는 창 share를 직접 회귀한다. 셀 분해/물리적 풀링 제약이 없으므로 새로운 주파수 채널 조건에서 과대·과소추정할 가능성이 남는다.

## 6. 이미 생성된 Tree 전용 제출물의 정확한 결합

구성 r∈{D0,H0}, Fold f∈{0,1,2,3,4}에 대해:

\[
\widehat y_{Tree}=\frac12\sum_r\frac15\sum_f\mathrm{clip}(g_{r,f}(d),0,1),\quad
s_{Tree}=\frac12\sum_r\frac15\sum_f p_{r,f}(d).
\]

즉 **10개 회귀기에 각각10%, 10개 독립 분류기에 각각10%**다. 신경망은 이 파일에 포함하지 않는다. 이 비율은 Test를 읽기 전에 고정했으며, local_fit 가중치 최적화도 하지 않았다.

최종 schema는 `ID, share_added_vessel, score_added_vessel`이며 1,500행이다. 원래 ID 순서를 보존하고, 숫자 CSV 저장·재읽기의 정확한 일치 및 SHA를 확인했다.

SHA256: `589bbee56ce9c8432aabd0da174ad040dd261410a84788293992cafd9d029490`.

## 7. 신경망 포함 앙상블: 적용 예정인 실제 코드

### 7.1 첫 Fold0 후보

각 구성 내부의 모델군은 `[Tree5 평균, CNN Fold0, FDY Fold0, iTransformer Fold0, TFGrid Fold0]`이다. 최종 가중치는 아직 학습 완료 후 결정되므로 현재 확정 숫자로 제시할 수 없다.

회귀 가중치는 **local_fit만** 사용하여 제한된 최소제곱으로 선택한다:

\[
\min_\alpha \frac1N\sum_i(X_i\alpha-y_i)^2
+10^{-4}\lVert\alpha-(.5,.125,.125,.125,.125)\rVert^2,
\]

`sum(alpha)=1`, `alpha_Tree≥0.5`, 각 NN 아키텍처 `0≤alpha≤0.25`. 구성 내부 정책을 각각 정한 뒤 D0/H0는 **50:50 고정**이다.

독립 score는 share를 섞지 않는다. local_fit AUC로 사전에 정한 네 후보 중 선택한다:

| 후보 | Tree | CNN | FDY | iTransformer | TFGrid |
|---|---:|---:|---:|---:|---:|
| tree_only | 1.00 | 0 | 0 | 0 | 0 |
| tree75_nn25 | 0.75 | 0.0625 | 0.0625 | 0.0625 | 0.0625 |
| tree60_nn40 | 0.60 | 0.10 | 0.10 | 0.10 | 0.10 |
| tree50_nn50 | 0.50 | 0.125 | 0.125 | 0.125 | 0.125 |

### 7.2 전체 5-Fold 후보

각 아키텍처의 Fold0~4 예측을 같은 가중치로 평균한 뒤, 위와 같은 5개 모델군의 cap 결합을 적용한다. D0/H0 비율과 독립 score 경로를 유지한다. Fold1~4는 기존 Fold0 가중치로 시작하지 않고 독립적으로 초기화한다.

전체 5-Fold 버전에서도 학습 원천은 현재 nested 배경과 A′75 참조다. 대상 음원이 자동으로 509개 전체로 확대되는 것은 아니다. Fold 수 증가와 독립 원천 다양성 증가는 서로 다른 개선이다.

후속 실행기는 연결 검사를 통과하고 대기 중이다. 첫 Fold0 CSV의 완료 기록·SHA·1,500개 고유 ID·출력 범위 및 모든 Fold0 모델 산출물을 확인한 후에만 Fold1~4를 시작한다. 32회 추가 학습을 각각100epoch로 수행하며, 전체 후속 학습·최종화 자체가 실행 완료된 것은 아니다. 상세 상태는 [후속 실행 상태](../ops/r16_multisupport_fivefold_r1/state.json)와 [연결 검증](../ops/r16_multisupport_fivefold_r1/CONNECTION_VERIFICATION.json)에 기록한다.

| zero 임계값·hard gating·score에 의한 share 억제 | **미적용** | 약한 양성을 잘못 0으로 만들 수 있음 |
| SAM 계열·LLM·RAG에 의한 마스크 후처리 | **미적용** | 현 입력과 과제에서 타당성·개선 미검증 |
| Test 분포·추정 사이트에 맞춘 스케일 변경 | **실시하지 않음** | 추론 이후 근거 없는 조정 방지 |

현재의 후처리는 **사전에 정한 집계와 범위 clip**이다. 고급 보정기를 적용해 성능 개선을 입증한 상태가 아니다.

## 9. Tree 전용 CSV의 출력 기술 통계 — 정답 평가가 아님

| 출력 | 평균 | 표준편차 | RMS | 중앙값 | p90 | 0.90 이상 |
|---|---:|---:|---:|---:|---:|---:|
| share | 0.247861 | 0.187001 | 0.310491 | 0.213524 | 0.522377 | 0.00% |
| 독립 score | 0.896956 | 0.185246 | 0.915885 | 0.985534 | 0.999293 | **75.13%** |

쉬운 해석:

- **share 평균 0.247861:** 각 15분 창의 추가 에너지 비율을 평균 약24.8%로 예측했다. 전체 원음의 선박 소리가 실제24.8%라는 뜻이 아니다. 창별 정규화 비율의 산술평균이다.
- **RMS 0.310491:** 예측값을 제곱한 평균의 제곱근이다. 큰 예측에 더 영향을 받는 분포 요약이며, **정답과의 오차 RMSE가 아니다.**
- **score 75.13%≥0.90:** 1,500개 중1,127개에 높은 추가 여부 점수를 줬다. 0.90을 실제90% 정답 확률로 해석하려면 별도 확률 교정 검증이 필요하다.

| 이전 후보 | 새 Tree와 share Pearson | 새 Tree와 share Spearman | 이전 share 평균 | 이전 share RMS |
|---|---:|---:|---:|---:|
| R9 Fold0 all5 | **0.968346** | **0.969220** | 0.264744 | 0.326982 |
| R14_step1 | 0.923931 | 0.932648 | 0.303326 | 0.386897 |

새 Tree의 share 평균은 R9보다0.016883 낮지만 순위는 매우 비슷하다. 이것만으로 일반화 문제가 해결됐다고 할 수 없다. score는 높은 값에 몰려 있다. **높은 점수를 많이 내는 것 자체는 높은 AUC나 올바른 확률 교정을 뜻하지 않는다.** 반대로 값이 높다는 사실만으로 AUC가 나쁘다고 단정할 수도 없다.

과거 공식 결과:

| 후보 | Public Score | RMSE | 진단 AUC |
|---|---:|---:|---:|
| R9 Tree 5-Fold만 | 0.768128675 | 0.231871324 | 0.548088888 |
| R9 Fold0 all5 | 0.782464193 | 0.217535806 | 0.555066666 |

과거 R9 Fold0 all5 회귀 가중치는 Tree60%, CNN/TFGrid/FDY/iTransformer 각10%였다. 해당 앙상블의 Tree도 Fold0 하나이며, 별도 Tree 전용 제출물은5-Fold 평균이었다. 따라서 두 공식 결과의 차이를 신경망 추가 효과만으로 분리할 수 없다.

**이번 Tree 전용 CSV의 공식 RMSE/AUC는 아직 미측정이다.**

## 10. 평가·누수 방지와 남은 한계

1. **shared local_fit은2,400행이지만 독립 배경은400창이다.** 같은 배경의6개 생성 연산자를 포함한다. 100epoch best 선택, 여러 모델, 결합 가중치 선택을 반복하므로 선택셋 과적합 가능성이 남는다. 작은 local_fit 오차를 공식 성능으로 읽으면 안 된다.
2. CV는 학습 중 best 선택이나 결합 가중치 선택에 쓰지 않는다. 모든 Fold 모델의 평균을 각 Fold CV에 적용하면 다른 Fold 모델이 그 원천을 학습했을 수 있다. **CV는 대응 Fold의 모델만으로 추론한 결과를 연결한다.**
3. 공통 gate/report/domain/native12 패널은 모델·정책을 고정한 뒤 평가한다. 그러나 과거 개발에서 반복 확인한 자료이므로 완전히 손대지 않은 최종 시험과 같지 않다.
4. A′75클립/13그룹, 유일한15분 이상 참조 그룹, R9 Fold0 TRAIN에 제한된 배경은 여전히 제약이다.
5. 분류기에 시간 특징·관측 비율이 들어간다. 자연 HF 변동과 인위적 추가를 구분하는지, mask/Nobs에 의존하는지 독립 검증이 필요하다. 현재 H0는 HF 음성 교체를 하지 않는다.
6. share는 전체 대역 에너지 비율이므로 HF bump 하나와 반드시 강하게 상관해야 하는 값이 아니다. HF bump 상관0.65 이상이나 예측 RMS0.24~0.27을 필수 성공 기준으로 둘 근거는 없다.
7. Benchmark 점수만으로 숨은 y의 평균·RMS를 유일하게 구할 수 없다. 특히 예측 상수가 불명확하면 `E[y²]=RMSE²`로 둘 수 없다. 예측 분포가 닮았어도 정답과 올바르게 대응한다는 보장이 없다.
8. Adversarial AUC가0.5에 가까워도 사용한 특징·분류기로 구분하지 못했을 가능성이 있다. `P(y|x)`와 합성 정답의 전달성까지 검증한 것은 아니다.
9. 작은 local RMSE나 예측 평균 하락을 이유로 공식0.78 초과나0.90 달성을 보장할 수 없다. 이번 CSV는 수정안을 확인하기 위한 **제출 후보**다.
10. 사전 파일럿의 native12/HF RMSE0.117553은 기준0.11에 미달했다. 사용자가 미달을 명시하고 진행하도록 승인한 상태이며, 이 조건을 통과했다고 표현하지 않는다.

## 11. 아르곤에게 요청할 검토 — 이 MD를 그대로 전달 가능

숨은 Test 라벨이나 리더보드 점수 역산 없이, 기존 TRAIN/fit/고정 교차 패널로 아래를 점검할 방법을 제안해 달라.

1. **독립 분류 score의 높은 값 집중**(평균0.897, 중앙값0.986, 75.13%≥0.9)은 TRAIN의80% 양성, binary logloss best 선택, 적은 참조 다양성 중 어떤 조건과 부합하는가? 확률 교정과 AUC를 구분해 fit/report의 Brier·logloss·reliability·rank를 어떻게 감사해야 하는가?
2. 새 Tree share와 옛 R9 share의 Pearson0.968/Spearman0.969를 볼 때, 어떤 대조 실험으로 “평균만 조금 낮아졌다”와 “교차 채널에서 조건부 회귀가 개선됐다”를 분리할 수 있는가?
3. 13개 참조 그룹과 유일한 장시간 그룹으로 참조 다양성 부족을 어디까지 검증할 수 있는가? Full5Fold와 독립 원음 추가의 효과를 혼동하지 않는 확장 방법은 무엇인가?
4. 상대 프로파일·sqrt(w)를 회귀에 남기고 분류에서는 제외한 구성에서, 장비/사이트 편법과 필요한 분모 정보를 어떻게 분리해서 감사할 수 있는가?
5. Tree≥50%, NN각≤25%, D0/H0 50:50은 사용자 지정 정규화이며 최적 성능을 보장하는 이론이 아니다. 독립 배경400창의 fit에서 결합을 선택할 때 어떤 불확실성 평가가 더 필요한가?
6. 후처리를 추가한다면 ①방법·탐색 범위·fit 대상을 먼저 고정, ②fit만으로 적합, ③교차 배경/참조/채널 및 site/HF/long에서 부작용 확인, ④Test 재적합 금지 조건으로 무엇을 하나씩 검증해야 하는가?
7. 원음을 모르는15×25 관측에서, 창 전체에 일정하게 더해진 성분과 원래 배경 레벨 변화가 식별 불가능해지는 조건은 무엇인가? 모델·후처리로 해결할 수 없는 정보 한계를 명시해 달라.

**검토 목적은 Test 분포의 목표 수치에 맞추는 것이 아니라, 생성·추론의 조건부 관계와 평가 설계가 올바른지 확인하는 것이다. 아직 입증하지 못한 개선은 미확정으로 남기고, 반증 가능한 검사를 우선해 달라.**
