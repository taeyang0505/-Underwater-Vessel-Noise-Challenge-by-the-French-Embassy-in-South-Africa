데이터 품질 감사와 GPU 학습 직전 준비

V1 원본과 제출 입력은 보존하고, 검증 가능한 V2 단일 holdout과 원천 기반 nested 5-fold 패키지를 새 경로에 구축했다. 아래 수치는 실제 파일과 에너지 계산을 재검증한 결과다. 모델 성능이나 자연 관측의 정답 정확도를 나타내지 않는다.

정답의 의미와 발견한 V1 문제

자연 SA 관측 1,715,779행은 검증된 선박 에너지 정답이 없다. 기존 teacher 점수는 낮은 source-heldout 성능으로 학습 라벨에 쓰지 않는다. 합성 target은 관측 mask O에서 y = Σ(O·αR) / Σ(O·(B+αR))로 계산한, 추가한 측정 reference의 에너지 비중이다. Reference에 포함된 자연 주변음까지 포함하므로 순수 선박만의 자연 정답이라고 부를 수 없다.

  • V1 저장 25,000개 target의 수학적 재검증은 통과했다. 다만 train 16,000개 중 원하는 양성 reference가 관측 mask 밖에만 놓여 693개가 0 target이 됐다. V2는 실제 관측 cell에 겹치게 배치하고 양성 겹침이 없으면 거부한다.
  • V1의 sensor-group/day 충돌 10일을 확인했다. V2는 공유 센서 그룹과 주 단위 원천 분할 후 24시간 support purge를 적용한다.
  • V1 validation 3,000개의 실제 positive reference는 5개 그룹에 불과했다. 합성 행 랜덤 KFold는 이 문제를 해결하지 못한다.
  • 전체 외부 WAV 1,670개의 checksum과 waveform QC를 재검증했다. VT 525개는 raw DC 지배 경고가 있으나 기존 공식 PSD는 constant detrend를 적용한다. 전체 corpus를 임의로 버리지 않았다.

Nested 5-fold의 독립 단위

이전 train+validation 원천만 사용한다. 배경은 100,965 windows, 258개의 sensor-group×week 블록이다. 외부 positive 1,171 clips: HMS 945/19일 그룹, NOAA 8/4 station, VT 218/88 hull 그룹. Hull·동일 녹음일·실제 시간 겹침·같은 byte를 연결하면 총 26 reference components(HMS 19, NOAA 4, VT 3)다.

Native 15분 reference 11 clips는 5개 독립 component(NOAA station 4개 + VT 연결 component 1개)다. 각 outer fold는 1개, inner는 다음 1개, train은 나머지 3개를 쓴다. Reference 원천은 outer fold 하나에만 배정한다. 배경 outer는 보존하고 train 및 inner 경계에서 24시간 purge하여 모든 실제 활성 분할 간격을 확보한다.

Inner validation만 early stopping·하이퍼파라미터·앙상블 가중치 선택에 사용하고, outer는 한 번 예측하여 OOF로 보고한다. Calibration·새 SB sealed·기존 OC02_02 평가·대회 Test는 fold 구성과 학습에서 제외했다.

경계 후보와 nominal sample-rate 경고

Train 원본만으로 run-edge 12,643행의 기존 후보 수를 독립적으로 정확 재현했다. 이 중 6,777행은 기존 window에 들어 있고, V2 train 5,817 / validation 437 / calibration 227 / purge 296개 window에 영향이 있다. 경계 레벨 상승의 물리 원인은 아직 검증되지 않았다. 모든 행은 보존하고 별도 flag만 저장했다.

URN_8321 136,518행의 metadata는 12 kHz이지만, 6.31 kHz band는 nominal Nyquist를 가로지르고 7.94 kHz band는 전부 초과한다. Exported 값은 존재한다. 원본 waveform/header와 provider 보정 경로를 확인하기 전에는 실제 fs, 보정값 또는 제거 규칙을 추측하지 않는다.

남은 과학적 한계와 학습 계약

  • Source 수가 작다. Sensor-week CV는 같은 센서의 시간 일반화를 측정하며 완전한 새 센서 일반화가 아니다. Native corpus가 fold별로 달라 fold 분산 및 corpus별 오차를 함께 보고해야 한다.
  • HMS hull 재등장 정보가 없어 일 분리만으로 실제 hull 독립성을 증명할 수 없다. NOAA Ship annotation도 순수 선박 에너지 분리를 증명하지 않는다.
  • NOAA는 고정한 public byte-range excerpt와 derived array SHA를 검증했다. Provider 전체 object MD5를 재계산했다고 주장하지 않는다.
  • V2에서 fitted scaler/context/KV cache와 V1 task-trained 가중치를 재사용하면 안 된다. Vendor 원본 pretrained checkpoint는 재사용할 수 있다.
  • Neural 학습은 사용자 설정 max 100 epochs, patience 7, Adam을 따른다. 실제 최적 epoch·종료 사유와 train/inner/outer 오차를 기록하여 과적합과 과소적합을 평가한다. 이 보고서를 만들면서 학습은 실행하지 않았다.
