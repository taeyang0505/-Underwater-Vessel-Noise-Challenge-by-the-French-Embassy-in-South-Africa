# 최종 확정 데이터 규모

현재 실제 저장·검증된 데이터는 R4 `group_cv_passage_r4_v1`입니다. R5는 이 원천과 동일한 합성 법칙을 매 epoch 새 seed로 사용합니다. 아직 만들지 않은 미래 epoch를 저장 샘플 수에 더하지 않았습니다.

| 구분 | 샘플 | 15분 창 길이 단순 합계 | 압축 NPZ 용량 |
|---|---:|---:|---:|
| TRAIN | 267,837 | 66,959.25시간 | 0.390338GB |
| INNER | 15,000 | 3,750.00시간 | 0.022016GB |
| OUTER | 15,000 | 3,750.00시간 | 0.021976GB |
| 합계 | **297,837** | **74,459.25시간** | **0.434330GB** |

위 시간은 **합성 15분 창의 환산 합계**이며, 그만큼 새 오디오를 실측했거나 모두 독립이라는 뜻이 아닙니다. 교차 fold에서 원천이 재등장합니다. TRAIN 고유 primary 배경 창은 **94,711개**입니다. 결측을 제외한 실제 관측 minute grid의 역할 합계 시간은 정량 JSON에 별도로 보관했습니다.

실제 원천 규모:

- 남아공 요약 관측 **1,715,779행**, 행 메타데이터 duration 합계 **28,358.33시간**. 여러 지점·수신기의 합계이며 원시 WAV는 제공되지 않았습니다.
- 현재 양성 참조로 선택한 VTUAD **119클립 / 22개 선택 그룹**, 클립 길이 합계 **8.63194시간**. 전체 수집 폴더의 미사용·격리 자료를 활성 학습 원천에 더하지 않았습니다.
- 정규 NPZ **15개**, **414.21MiB**. 압축을 푼 정규 배열 payload는 **0.895894GB**입니다.
- 바탕화면 프로젝트 전체는 약 **23.1GB**이며 원본·미사용 외부 자료·공개 가중치·구버전 합성·서버 백업·보고서가 함께 포함됩니다. 이 전체 용량이 현재 학습 NPZ 크기는 아닙니다.
