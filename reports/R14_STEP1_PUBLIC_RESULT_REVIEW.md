사용자가 전달한 Zindi 화면의 결과를 기록했다. 직접 서버에서 조회한 결과는 아니며, 실제 업로드 바이트의 SHA는 확보하지 못했다. 로컬 후보 CSV SHA는 `947c71dcc52d50fa2e3f63a6bbc3859cca9413169847697a509199c4d5da70a4`로 기존 완료 영수증과 일치한다.

|---|---:|---:|---:|
| R9 Fold0 all5 | 0.782464193 | 0.217535806 | 0.555066666 |
| R14 Step1, 제출 ID 2bYLCv2z | 0.705436197 | 0.294563802 | 0.497866666 |
| Benchmark | 0.753867825 | 0.246132175 | 미확인 |

R9 대비 RMSE는 0.077027996(35.41%), MSE는 83.36% 증가했다. AUC는 0.057200 감소해 관측상 무작위 수준이다. 신뢰구간이나 유의성 검정을 수행한 것은 아니다.

## 확인된 정보

- 로컬 개발 패널 RMSE 개선이 이번 Public 개선으로 전달되지 않았다. 해당 패널의 우수성을 공식 일반화의 증거로 사용할 수 없다.
- 실제 회귀 비중은 CNN 81.047%, 기본 Tree 16.716%, highshare Tree 2.236%다. FDY/iTransformer의 비중은 사실상 0이다.
- 기존 로컬 R9 CSV 대비 새 share 평균은 0.264744→0.303326, RMS는 0.326982→0.386897로 커졌다. 다만 숨겨진 정답이 없어 실제 평균 편향이나 과대추정 원인은 측정할 수 없다.
- score ROC-AUC가 약 0.5이므로 오차가 단순 share 크기 문제에만 국한된다고 볼 수 없다. score의 양의 단조 변환으로 순위 AUC를 고칠 수 없다.
- Test 1,500 ID와 로컬 제출/저장 예측 ID 순서, 헤더, 값 범위, 저장 예측과 CSV의 수치 일치 및 375열 minute-major 매핑에서 명백한 오류는 발견하지 못했다. 이는 모델 수식 전체나 실제 업로드 파일까지 검증했다는 뜻은 아니다.
- TFGrid, TimeMoE, Dasheng은 이번 CSV에 포함되지 않았다. 이들의 실패나 구제 효과를 이 결과에서 판단할 수 없다.

## 아직 분리하지 못한 원인과 다음 진단

입력 14채널/LF anchor/PCA, 장시간·고SNR·HF 음성 레시피, 학습 기간, 회귀·분류 결합, F0 정책을 Tree5 평균에 확장한 효과가 함께 바뀌었다. CNN 비중이 높다는 사실만으로 CNN 자체를 단독 원인으로 지목할 수 없다.

다음 원인 분리는 동일한 원천·마스크·정답·합성 패널에서 R9/R14의 입력·레시피·앙상블 요소를 하나씩 비교하는 방식으로 해야 한다. 이미 확인한 17패널은 개발 노출 패널로 표시하고 새로 고정한 센서/생성 연산자 조합도 함께 평가한다. Public 점수로 가중치나 Test 출력 RMS를 직접 맞추지 않는다. 단순 Fold 수 또는 모델 크기 증가가 공통 데이터/검증 편향을 자동으로 해결한다고 보지 않는다.

이번 검토에서는 동결된 학습·정책·기존 결과를 변경하거나 재학습·추론·공식 업로드하지 않았다. TFGrid 학습은 유지했다.
