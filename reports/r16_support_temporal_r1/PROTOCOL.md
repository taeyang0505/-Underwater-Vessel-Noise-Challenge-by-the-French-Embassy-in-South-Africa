# R16 자연 support·시간 구조 보완: 사전 고정 실험

## 범위와 변경 금지

사용자가 승인한 두 보완만 2×2로 비교한다. 기존 R16 학습·데이터·체크포인트와 일시 정지 상태는 보존한다. 실제 결과를 읽고 조건을 추가 탐색하지 않는다. Test 및 Test 유래 통계로 생성기·특징·정책을 적합하지 않는다. 인위적인 평탄 15분, 시간 늘림/반복, highshare 강제 할당, PCA/LF anchor 및 절대 dB 입력은 추가하지 않는다.

## 네 조건

| 조건 | DATA | FEATURE |
|---|---|---|
| D0F0 | 공통 새 A′ 풀 + 기존 geometry/음성 | 기존 R16 상대 입력/분류 특징 |
| D0F1 | D0와 동일 | 다중 시간 지속성·곡률·동조 추가 |
| D1F0 | 자연 native 장구간 + matched HF 음성 보강 | 기존 특징 |
| D1F1 | D1과 동일 | 시간 구조 추가 |

네 조건은 같은 A′ 참조 roster, 양성의 원배경·참조 ID·연산자/EQ/SNR 난수를 공유한다. HF 교체로 음성 배경 ID는 달라질 수 있으므로 이를 완전히 같은 원자료라고 부르지 않는다. 교체 쌍의 site/sensor/recorder/관측 마스크는 같아야 한다. 과거 동결 R16 mixed는 역사적 비교 행이며 D0F0와 동일 모델이 아니다.

## 원천 분할

A′는 기존 A 66클립에 기존 C의 19/20/23분 클립이 속한 컴포넌트 **전체 9클립(장시간3개+연결 단편6개)**을 더한 75클립·13컴포넌트다. B 19클립·5컴포넌트는 유지한다. C′는 나머지 25클립·4컴포넌트이며 독립 12분 컴포넌트를 보존한다. 최초 메타데이터 수량 검사에서 장시간3개만을 컴포넌트 전체로 세었던 오류를 생성·학습 전에 바로잡았다. 기존 C를 포함했던 점수는 새 분할에서 다시 분리 보고한다.

독립된 15분 이상 원천은 현재 학습에 편입한 단 하나의 컴포넌트뿐이다. 새 평가 원천은 12분이므로, 15분 미관측 원천 일반화를 입증했다고 주장하지 않는다. 고정 R11 native15가 학습 컴포넌트와 겹치면 reference-seen 진단으로 표시한다. 전체 509개 풀의 연결 그래프와 119개 선택 풀의 조건부 그래프 독립성을 구별한다.

## 학습·점수

- 각 DATA 4,000행, 명시적 무추가 800행을 유지한다. 물리적 share/cell_share는 알려진 B+A 식 그대로 계산한다.
- CNN은 100epoch, Adam, dropout 0.1, early stopping 없이 실행한다. 회귀·분류 체크포인트를 local_fit에서 각각 선택한다.
- Tree는 기존 파일럿과 같은 최대600회/early stopping40, 회귀·독립 분류를 분리한다.
- CNN 회귀는 share MSE + 0.25 × 에너지 가중 cell MSE, 물리 풀링을 유지한다. BCE가 회귀 마스크 파라미터를 바꾸지 않는다.
- 보강된 분류 특징은 고정 대역 offset에 불변인 시간 구조만 사용한다. 회귀 모델의 TRAIN 자체 예측을 분류 입력으로 사용하지 않는다. 이는 별도의 OOF 구성 없이는 누수 단서가 될 수 있기 때문이다.
- 사전 고정 결합은 share=0.6 Tree+0.4 CNN, score=0.5 Tree classifier+0.5 NN classifier다. share를 score에 섞거나 평가 패널에서 가중치를 피팅하지 않는다. 개별 모델도 모두 보고한다.

## 동결 및 평가 순서

네 모델의 학습·체크포인트 선택이 전부 끝난 후 코드·데이터·가중치·결합 정책 SHA를 동결한다. 이후 별도 배경 local_gate, C′ 별도 참조/크롭 local_report, 미관측 사이트 domain_holdout의 6개 연산자를 각각 평가한다. 새 독립 native12 양성과 HF/SF 음성 대조, 기존 R11 공개된 스트레스는 후속 진단으로만 평가한다.

주 기준은 별도 배경·참조·사이트와 독립 LF/HF 채널 전이다. R11 평탄15 성능은 모델 선택 조건이 아니다. 새 장시간 대조에서 양성/음성은 각각 총 가중치 0.5로 RMSE를 보고하고 원래 행 비율의 RMSE도 함께 보관한다.

사전 실행 판단 기준은 고정 결합 D1F1 대 D0F0에서 다음과 같다.

1. 세 주 교차 축 각각의 RMSE 악화가 max(0.005, 기준 RMSE의 5%) 이내이고 독립 분류 AUC 하락이 0.02 이내인가. 연산자별 악화도 숨기지 않고 전부 공개한다.
2. 새 원천 독립 native12 vs HF 및 vs SF의 classifier AUC가 모두 0.75 이상인가(목표 0.80 이상).
3. HF 무추가 평균 classifier 확률이 기준 대비 0.10 이상 또는 25% 이상 감소하고, 해당 음성의 share 과대추정이 0.01 넘게 악화되지 않는가.

위 조건을 통과해야 수정 데이터의 본체 연결로 진행한다. 통과하지 못하면 실제 실패를 보고하며 추가 탐색을 성공처럼 포장하지 않는다. 통과해도 공식 LB 개선이나 모든 데이터 간극 해소를 보장하지 않는다. 장시간 홀드아웃 컴포넌트가 하나뿐인 통계적 한계를 명시한다.

## 확정 사실과 가설의 구별

12분 이상 TRAIN 양성 0건과 장시간/HF 점수 역전은 측정됐다. 그러나 자연 HF가 모두 1분 스파이크이거나 선박과 시간 특징만으로 100% 구분된다는 것은 측정된 사실이 아니다. 고정 R11과 실제 Test의 조건부 분포가 동일하다는 근거도 없다. 본 실험은 이 보완의 전달성을 제한된 원천에서 검증한다.
