# R5 원천 이상값·품질 선별 비율 감사

실제 Parquet 메타데이터를 다시 집계한 결과, **초기 분 단위 입력 선별에서 빠진 행은 17,555 / 1,715,779 = 1.02315%**입니다. 이와 별도로 현재 R4/R5 TRAIN은 경계 후보를 포함한 **창 전체의 4.84978~6.69107%를 이미 제외**합니다. 원본 1,715,779행은 모두 보존되어 있습니다.

검토 후보와 장비 메타데이터 경고를 모두 오류라고 합산할 수는 없습니다. 특히 높은 dB 또는 높은 합성 정답 share는 이 감사에서 이상치로 정의하지 않았습니다. **추가 제외의 성능 개선 효과는 측정하지 않았습니다.**

## 1. 원본 행 기준: 오류 플래그와 후보를 구분

아래 비율의 분모는 모두 원본 **1,715,779행**입니다. 항목끼리 중복됩니다.

| 항목 | 실제 행 수 | 비율 | 의미·현행 처리 |
|---|---:|---:|---|
| 공통 25대역 nonfinite 플래그 | 0 | 0% | `qc_25band_finite`는 전 행 True |
| sentinel 포함, invalid measurement 표시 | 653 | 0.03806% | `sentinel_like`; 입력 창에서 제외, 원본 행 보존 |
| duration <55초 | 16,896 | 0.98474% | 충분한 길이의 분 관측으로 간주하지 않음 |
| duration >65초 | 22 | 0.00128% | 55~65초 입력 규칙 밖 |
| duration 범위 이탈 합계 | 16,918 | 0.98602% | 불완전·비표준 길이이며 모두 녹음 오류라는 뜻은 아님 |
| timestamp 초 부분 >5 | 7,672 | 0.44714% | 이번 자료에서는 전부 duration 범위 이탈과 중복 |
| run 경계 후보 전체 | 12,643 | 0.73687% | 통계적 후보. 기기 원인은 미검증 |
| 그중 원래 고정창에 포함된 경계 후보 | 6,777 | 0.39498% | 12,643개 전체 후보의 53.60278% |
| URN_8321 nominal sampling-rate 경고 | 136,518 | 7.95662% | 12kHz 메타데이터와 상위 대역 범위의 불일치. 일괄 삭제하지 않음 |
| 25대역 spread <6dB 플래그 | 4,974 | 0.28990% | 정상적인 일정한 스펙트럼일 수도 있어 단독 hard rejection 아님 |

`negative_level`은 654행으로 sentinel 653행과 다릅니다. 나머지 한 행은 row_id 633100, duration 40초이며 이미 창에 포함되지 않았습니다. 그러므로 “sentinel 654행”이라고 표현하면 부정확합니다. `pseudo_label_status`는 초기 준비 단계의 상태 필드이며 자연 선박의 정답 라벨을 뜻하지 않습니다.

별도 `severe_duration` 컬럼은 없습니다. 심하게 짧은 관측의 크기를 보기 위한 **서술적 구간** `1≤duration<5초`는 10,968행(0.63924%)입니다. duration 최솟값은 1초, 최댓값은 360초이며 비유한 값·0 이하·1초 미만은 각각 0행입니다. 5~30초 미만은 2,994행, 30~55초 미만은 2,934행입니다. 이 구간을 새 오류 판정 기준으로 채택하지 않았습니다.

## 2. 중복·합집합과 실제 초기 선별

| 교집합 또는 합집합 | 행 수 | 원본 대비 비율 |
|---|---:|---:|
| sentinel/invalid ∩ duration 범위 이탈 | 16 | 0.00093% |
| duration 범위 이탈 ∩ 경계 후보 | 5,863 | 0.34171% |
| duration <5초 ∩ 경계 후보 | 5,312 | 0.30960% |
| 경계 후보 ∩ URN 경고 | 0 | 0% |
| duration 범위 이탈 ∩ URN 경고 | 44 | 0.00256% |
| 초기 선별 부적합의 합집합 | **17,555** | **1.02315%** |
| 전체 경계 후보 ∪ URN 경고 | 149,161 | 8.69349% |
| 창에 포함된 경계 후보 6,777 ∪ 전체 URN 경고 | 143,295 | 8.35160% |
| 창에 포함된 경계 후보 ∪ 창에 포함된 URN 경고 | 143,250 | 8.34898% |
| invalid ∪ duration 범위 이탈 ∪ 전체 경계 후보 ∪ URN 경고 | 160,809 | 9.37236% |

뒤의 큰 합집합 비율은 **확정 오류율이 아닙니다**. 오류 플래그, 정렬 부적합, 통계적 후보, 메타데이터 경고를 합친 크기입니다. 상세 교집합 행렬과 각 분모는 [정량 JSON](R5_OUTLIER_AUDIT.json)에 있습니다.

현행 초기 조건은 공통 25대역 finite, sentinel 없음, `55≤duration≤65`, timestamp 초 부분≤5입니다. 이를 통과한 행은 1,698,224행(98.97685%)입니다. 분 중복 선택 및 최소 3개 관측 분의 고정창 조건까지 적용한 실제 창 포함 행은 **1,698,184행(98.97452%)**입니다. 두 단계 사이의 40행을 포함하여 창에 들어가지 않은 총량은 17,595행(1.02548%)입니다. 40행의 개별 원인을 이 감사에서 추정하지 않았습니다.

초 부분이 0이 아닌 행은 21,082개이지만, 현행 규칙은 1~5초를 허용하므로 이것을 모두 제외 수로 사용하면 안 됩니다. invalid·duration 이탈·초 부분>5인 행은 실제 고정창 포함 행 중 각각 **0개**입니다.

## 3. 실제 TRAIN 창: 이미 적용된 경계 후보 제외

분모는 원본 171만 행이 아니라, **각 fold의 역할 배정·시간 purge를 마친 TRAIN 원천 창**입니다. 하나의 창은 관측 분 3~15개를 포함할 수 있습니다.

| Fold | 경계 제외 전 TRAIN 창 | 경계 포함으로 제외 | 제외율 | 실제 clean TRAIN 창 | clean TRAIN 내 URN 경고 창 |
|---|---:|---:|---:|---:|---:|
| 0 | 56,789 | 3,545 | 6.24241% | 53,244 | 4,185 / 7.86004% |
| 1 | 57,095 | 3,780 | 6.62054% | 53,315 | 4,068 / 7.63012% |
| 2 | 57,360 | 3,838 | 6.69107% | 53,522 | 4,075 / 7.61369% |
| 3 | 56,633 | 3,635 | 6.41852% | 52,998 | 3,739 / 7.05498% |
| 4 | 57,549 | 2,791 | 4.84978% | 54,758 | 4,225 / 7.71577% |

5fold 반복 원천 항목을 합하면 285,426개 중 17,589개(6.16237%)를 제외하여 267,837개 TRAIN 항목을 사용합니다. **서로 독립인 267,837개 원천이라는 뜻은 아닙니다.** 중복을 없앤 원천 창은 clean TRAIN 94,711개, 경계 제외 6,254개입니다. 이 둘은 R4 공통 원천 풀 100,965개를 이룹니다.

현행 규칙은 후보 **행 하나만 마스킹하는 방식이 아니라 후보를 포함한 창 전체를 제외**합니다. 예를 들어 fold 0은 후보 행 3,545개가 들어 있는 창을 빼면서 그 창의 원래 관측 행 52,014개를 TRAIN 입력에서 제외합니다. 파일을 삭제하거나 원본 관측을 고친 것은 아닙니다.

### 원천 지역의 지지 범위도 줄어든 상태

| Fold | Cape_Recife 제외 전→실사용 창 | Riy_Banks 제외 전→실사용 창 |
|---|---:|---:|
| 0 | 240→0 | 204→0 |
| 1 | 408→0 | 317→0 |
| 2 | 240→0 | 207→0 |
| 3 | 120→0 | 113→0 |
| 4 | 120→0 | 110→0 |

이 두 지역은 현재 TRAIN 배정 창 모두가 경계 후보를 포함하여 전부 제외됩니다. 따라서 추가 제외가 단순히 잡음만 줄인다고 볼 수 없습니다. 학습에서 다루는 환경 범위를 더 줄일 수 있습니다. **이 사실만으로 기존 제외가 성능 저하의 원인이라고 확정하지도 않습니다.** INNER/OUTER 원천에는 경계 후보 플래그를 유지하며, 이 감사는 그 관측 배열이나 성능 값을 열지 않았습니다.

## 4. 원천 풀 선택과 오류 제거를 혼동하지 않기

원래 고정창은 133,641개입니다. R4가 사용하는 100,965개는 활성 `quality_v2` 원천 역할의 TRAIN 91,186개와 validation 9,779개입니다. 예약 calibration, domain holdout, 시간 purge 역할은 여기에 포함되지 않습니다. 32,676개 차이를 모두 이상치 제거 수로 간주하면 안 됩니다.

원본 고정창의 초기 V1 split 이름과 이후 quality_v2 역할은 다릅니다. 예를 들어 R4 풀의 일부에 초기 V1 `calibration` 이름이 남아 있지만, 활성 quality_v2에서 다시 확인한 R4 원천 역할은 TRAIN/validation뿐입니다. 정량 JSON에는 역사적 역할과 활성 역할을 구분해 기록했습니다.

## 5. 성능에 대해 현재 말할 수 있는 범위

이번 감사에서 재학습·새 제외 실험·공식 제출을 하지 않았으므로, **“극단값을 더 제외하면 RMSE가 얼마나 개선된다”는 수치는 없습니다.** 원본 dB가 높거나 합성 정답 share가 크다는 이유로 삭제하면 실제 강한 선박 신호나 유효한 높은 에너지 기여율을 잃을 수 있습니다. 현행 경계 제외만으로도 두 지역의 TRAIN 창이 0개가 된다는 점을 함께 고려해야 합니다.

추가 선별을 비교하려면 보존된 원천·동일한 fold/purge·동일 모델/seed/예산을 유지하고, TRAIN 처리만 달리한 사전 정의 실험으로 고정 INNER에서 비교해야 합니다. 이번 감사는 그 실험을 실행하거나 OUTER/Test에 맞춰 기준을 정하지 않았습니다. R4 데이터·manifest·기존 결과는 변경하지 않았습니다.

## 6. 출처와 재현

실제 컬럼 스키마를 읽고 boolean·duration·timestamp·row_id를 집계했습니다. 새로운 음압 수치 임계값이나 정답 share 임계값은 만들지 않았습니다. 원천 배열·예측 파일·heldout recipe는 읽지 않았습니다. 열린 메타데이터의 SHA256은 집계 후 다시 대조하여 모두 동일했습니다.

- [원본 row manifest](../data/processed/sa_row_manifest.parquet): SHA256 `e05004b977bf7db91f131ffe2d87d944a135de48685591d484aa53294bf29de4`
- [기존 경계 후보 metadata](data_quality_boundary_flags.parquet)
- [Fold 0 실제 원천 metadata](../data/synthetic/group_cv_passage_r4_v1/fold_00/sources/background_manifest.parquet), 나머지 4fold도 같은 상대 경로 체계
- [전체 원천 SHA·스키마·겹침·분할별 수치](R5_OUTLIER_AUDIT.json)
- 기존 정의: [원본 준비 코드](../pipeline/prepare_sa.py), [경계 후보 정의](../pipeline/boundary_audit_v2.py), [학습 창 제외 적용](../pipeline/build_physics_cv_v2.py). 이 감사에서 해당 파일을 수정하지 않았습니다.

핵심 분모를 재현하는 집계식은 다음과 같습니다(`m`: 원본 row manifest, `b`: 각 fold background manifest).

```python
rejected = (~m.qc_25band_finite | m.sentinel_like | ~m.dur.between(55, 65) | m.t.dt.second.gt(5)).sum()
train_boundary_ratio = b.loc[b.parent_split.eq('train'), 'boundary_candidate_flag'].sum() / b.parent_split.eq('train').sum()
```

`rejected`는 17,555행이며, fold 0의 `train_boundary_ratio`는 3,545 / 56,789입니다. 더 자세한 교집합·합집합과 지역별 집계식은 정량 JSON에 기록했습니다.
